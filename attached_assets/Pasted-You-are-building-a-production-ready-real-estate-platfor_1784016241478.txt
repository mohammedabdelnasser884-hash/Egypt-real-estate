You are building a production-ready real estate platform for Egypt.

This is the technical blueprint for the first serious version of the product.
The app must be Arabic-first, mobile-first, trust-first, and optimized for daily usage and return visits.

Important product goal:
This is not a classifieds website.
It is a structured real estate platform with verified listings, office profiles, saved searches, property tracking, and a daily feed that builds user habit.

Recommended stack:
- Next.js App Router
- TypeScript
- Tailwind CSS
- shadcn/ui or equivalent component system
- Prisma ORM
- PostgreSQL
- NextAuth or a simple auth layer
- Zod for validation
- Server Actions and/or API routes
- Optional future support for image upload, notifications, and AI features

Do not implement monetization in this version.
No payments.
No subscriptions.
No commissions.
No advertising system yet.

Build a clean and scalable architecture.

3) API ROUTES
==================================================

Create REST-like routes or server actions for:

GET /api/listings
- supports filters, search, sorting, pagination

GET /api/listings/[id]
- returns full property details

POST /api/listings
- create listing

PATCH /api/listings/[id]
- update listing

DELETE /api/listings/[id]
- soft delete or remove listing

GET /api/offices

==================================================
6) PRODUCT RULES
==================================================

The app must enforce these rules:

- Verified badges must be visible on listings and offices.
- Every listing must show last updated.
- Duplicate listings should be prevented or flagged.
- Reports must be easy to submit.
- Saved searches must be easy to create.
- Daily feed must surface fresh content first.
- Price status must be shown clearly.
- The UI must feel alive even with seed data.
- Arabic text must render properly and the layout must support RTL.
- Mobile UX is a priority.
- Dashboard and public app must be separated cleanly.
